# Flickey

## 개인 맞춤형 모션 프레젠테이션 인터페이스

---

## 1. 한 줄 정의

발표자의 평소 몸짓을 미리 학습해 오작동을 줄이고, 사용자가 설정한 손동작으로 슬라이드·커서·레이저·발표 자료를 제어하는 모션 프레젠테이션 도구.

---

## 2. 제품 콘셉트

> 발표자의 말과 흐름을 끊지 않는 개인 맞춤형 모션 컨트롤러

Flickey는 단순히 손동작으로 슬라이드를 넘기는 발표 리모컨이 아니다.

사용자가 실제 발표처럼 리허설하는 모습을 먼저 분석해 평소 무의식적으로 자주 사용하는 몸짓을 파악한다. 실제 발표 중에는 이러한 자연스러운 몸짓을 명령으로 잘못 인식하지 않고, 사용자가 의도적으로 설정한 제스처만 실행한다.

슬라이드 이동뿐만 아니라 커서 조작, 레이저 포인터, 링크 클릭, 파일 및 웹사이트 실행까지 하나의 모션 인터페이스에서 제어하는 것이 목표다.

---

## 3. 핵심 슬로건

또는

> 당신의 몸짓을 이해하는 프레젠테이션 인터페이스.

## 4. 주요 타깃

### 핵심 타깃

카메라 앞에서 자료를 공유하며 설명하는 온라인 발표자.

- 온라인 강사
- 교사 및 교수
- 대학생과 대학원생
- 웨비나 진행자
- 비대면 영업 담당자
- 제품 시연 담당자
- 사내 발표가 많은 직장인
- 온라인 콘텐츠 진행자

### 주요 사용 환경

- Zoom
- Google Meet
- Microsoft Teams
- 온라인 강의
- 웨비나
- 제품 시연
- 화면 공유형 회의
- 오프라인 프로젝터 발표
- 발표 영상 녹화

### 타깃의 공통 문제

- 발표 도중 마우스와 키보드를 찾으면 흐름이 끊긴다.
- 화면을 조작하는 동안 청중과의 시선이 단절된다.
- 기존 발표 리모컨은 슬라이드 이동 외 기능이 부족하다.
- 온라인 발표에서는 물리적인 레이저 포인터를 사용할 수 없다.
- 사람마다 말할 때 사용하는 몸짓이 달라 일반 제스처 시스템은 오작동하기 쉽다.
- 발표에 필요한 링크, 영상, PDF, 프로그램을 빠르게 전환하기 어렵다.

## 5. 핵심 가치

### 개인 맞춤형 오작동 방지

발표 리허설을 통해 사용자가 평소 사용하는 몸짓을 분석하고, 명령 제스처와 충돌하지 않도록 한다.

### 발표 흐름 유지

발표자가 키보드나 마우스를 찾지 않고 청중을 바라보며 발표를 이어갈 수 있다.

### 통합된 발표 제어

슬라이드, 커서, 레이저, 링크, 파일, 영상, 프로그램을 하나의 모션 인터페이스로 제어한다.

### 별도 하드웨어 불필요

노트북이나 데스크톱 웹캠만 있으면 사용할 수 있다.

### 사용자별 커스터마이징

사용자가 제스처, 실행 명령, 유지시간, 민감도, 사용 손을 직접 설정할 수 있다.

## 6. 핵심 차별점

### 기존 발표 리모컨과의 차이

| 기존 발표 리모컨 | Flickey |
| --- | --- |
| 별도 하드웨어 필요 | 웹캠만으로 사용 |
| 다음·이전 슬라이드 중심 | 커서·레이저·자료 실행 지원 |
| 버튼이 고정되어 있음 | 모션과 명령을 직접 설정 |
| 발표자의 몸짓을 고려하지 않음 | 리허설을 통해 평소 몸짓 분석 |
| 온라인 레이저 사용이 제한적 | 화면 위 소프트웨어 레이저 제공 |
| 실행 여부를 손에서 확인하기 어려움 | 손 주변 효과로 즉시 피드백 |

### 기존 제스처 프로그램과의 차이

기존 프로그램은 정해진 제스처를 사용자가 외워야 한다.

Flickey는 사용자가 평소 어떤 몸짓을 사용하는지 먼저 확인한 뒤, 오작동 가능성이 낮은 제스처를 추천한다.

## 8. 발표 리허설 학습

### 목적

리허설 학습은 발표 내용이나 사용자의 얼굴을 학습하는 기능이 아니다.

발표 중 자연스럽게 나타나는 손 모양과 움직임을 분석해, 명령 제스처와 충돌할 가능성을 줄이는 기능이다.

### 학습 방식

사용자가 실제 발표처럼 1~3분 동안 카메라 앞에서 말한다.

가능하다면 실제 발표 자료를 사용해 슬라이드를 설명하도록 한다. 시스템은 촬영된 영상에서 손 관절 좌표와 움직임을 추출한다.

### 분석할 데이터

- 주로 사용하는 손
- 양손을 사용하는 빈도
- 손을 올리는 평균 높이
- 손이 움직이는 일반적인 범위
- 자주 등장하는 손가락 모양
- 손바닥을 펼치는 빈도
- 주먹을 쥐는 빈도
- 좌우 이동 빈도
- 평균 이동 거리
- 평균 이동 속도
- 평균 동작 유지시간
- 손이 자주 머무르는 위치
- 반복적으로 등장하는 동작 패턴

### 분석 결과 예시

> 오른손 손바닥 펼치기는 발표 중 자주 사용됩니다. 명령 제스처로 권장하지 않습니다.

> 왼손 V 사인은 평소 거의 나타나지 않습니다. 슬라이드 이전 명령으로 사용할 수 있습니다.

> 양손을 동시에 사용하는 빈도가 낮습니다. 모드 전환이나 발표 종료처럼 중요한 명령에 적합합니다.

## 9. 개인화 구현 방식

평소 자주 사용하는 포즈를 무조건 금지하면 시스템이 지나치게 둔해질 수 있다.

따라서 Flickey는 손 모양만 보는 것이 아니라 다음 정보를 함께 사용해 의도적인 명령인지 판단한다.

- 손 모양
- 손의 위치
- 이동 방향
- 이동 거리
- 이동 속도
- 유지시간
- 시작 포즈와 종료 포즈
- 사용하는 손
- 양손 사이의 관계
- 현재 작동 모드

예를 들어 발표자가 평소 오른손 손바닥을 자주 펴더라도 다음과 같은 조합은 별도의 명령으로 구분할 수 있다.

```
오른손 손바닥 펼치기
→ 어깨 높이 위로 올리기
→ 오른쪽으로 일정 거리 이상 빠르게 이동
```

## 10. 제스처 충돌 위험도

리허설이 끝나면 사용할 수 있는 제스처마다 충돌 위험도를 표시한다.

### 위험도 단계

- 안전: 평소 발표에서 거의 나타나지 않는 동작
- 주의: 가끔 등장하지만 위치나 이동 조건으로 구분할 수 있는 동작
- 위험: 발표 중 자주 반복되는 동작

### 결과 예시

| 제스처 | 평소 사용 빈도 | 충돌 위험 | 권장 설정 |
| --- | --- | --- | --- |
| 오른손 손바닥 펼치기 | 높음 | 위험 | 명령 사용 비추천 |
| 왼손 V 사인 | 낮음 | 안전 | 이전 슬라이드 |
| 양손 검지 교차 | 매우 낮음 | 안전 | 모드 선택 |
| 오른손 좌우 이동 | 중간 | 주의 | 이동 거리 조건 추가 |
| 왼손 주먹 쥐기 | 낮음 | 안전 | 클릭 |

## 11. 발표 제어 모드

Flickey는 기능을 모드별로 분리해 오작동을 줄인다.

### 슬라이드 모드

발표를 시작했을 때의 기본 모드다.

지원 기능:

- 다음 슬라이드
- 이전 슬라이드
- 첫 슬라이드로 이동
- 특정 슬라이드로 이동
- 발표 시작
- 발표 화면 가리기
- 발표 화면으로 복귀
- 미리 등록한 자료 실행

### 커서 모드

슬라이드나 웹페이지 안의 링크, 버튼, 영상을 선택할 때 사용한다.

지원 기능:

- 오른손으로 커서 이동
- 왼손 펼치기 후 주먹 쥐기로 클릭
- 링크 열기
- 버튼 선택
- 영상 재생 및 정지
- 웹페이지 스크롤

커서 모드에서는 슬라이드 이동 제스처를 일시적으로 비활성화한다. 커서를 움직이다가 슬라이드가 잘못 넘어가는 상황을 방지하기 위해서다.

### 레이저 모드

발표 화면의 특정 내용을 강조할 때 사용한다.

지원 기능:

- 오른손 위치에 맞춰 레이저 이동
- 레이저 크기와 색상 설정
- 이동 경로에 짧은 잔상 표시
- 손을 멈추면 해당 위치 강조
- 주먹을 쥐면 강조 원 확대
- 일정 시간 후 표시 자동 제거

레이저 모드에서는 실제 시스템 커서를 움직이지 않는다. 따라서 발표 중 링크나 버튼을 실수로 클릭하지 않는다.

### 자료 모드

발표 전에 등록한 파일이나 링크를 빠르게 호출하는 모드다.

등록 가능한 자료:

- 웹사이트
- PDF
- 이미지
- 영상
- 로컬 파일
- Finder 폴더
- 특정 애플리케이션
- 데모 페이지
- 특정 슬라이드

## 12. 모드 전환 방식

모드 전환은 발표 중 흔히 나오지 않는 복잡한 제스처를 사용해야 한다.

### 추천 방식: 진입 모션 후 방향 선택

```
양손 검지를 교차해 일정 시간 유지
→ 왼쪽 이동: 커서 모드
→ 오른쪽 이동: 레이저 모드
→ 아래로 이동: 슬라이드 모드
```

### 장점

- 우연히 모드가 변경될 가능성이 낮다.
- 하나의 진입 동작만 기억하면 된다.
- 새로운 모드를 추가하기 쉽다.
- 현재 모드에 따라 같은 동작을 다르게 해석할 수 있다.

### 모드 전환 피드백

모드가 바뀌면 화면 가장자리에 상태를 짧게 표시한다.

- `SLIDE MODE`
- `CURSOR MODE`
- `LASER MODE`
- `MOTION OFF`

## 13. 추천 기본 제스처

아래 동작은 기본 예시이며, 리허설 결과에 따라 사용자별로 다르게 추천한다.

| 기능 | 추천 제스처 |
| --- | --- |
| 다음 슬라이드 | 오른손을 오른쪽으로 짧게 밀기 |
| 이전 슬라이드 | 왼손을 왼쪽으로 짧게 밀기 |
| 커서 이동 | 오른손 검지와 중지 펴기 |
| 클릭 | 왼손 펼치기 후 주먹 쥐기 |
| 레이저 이동 | 오른손 검지만 펴기 |
| 모드 선택 | 양손 검지 교차 후 유지 |
| 자료 메뉴 | 왼손으로 L 모양 만들기 |
| 발표 화면 복귀 | 손바닥을 아래로 내리기 |
| 모션 잠금 | 양손으로 X를 만든 후 유지 |
| 모션 활성화 | 지정한 복합 포즈 유지 |

중요한 명령일수록 한 손 정적 포즈보다 양손이나 연속 동작을 사용하는 것이 안전하다.

## 14. 발표 자료 사전 등록

발표자는 발표를 시작하기 전에 필요한 파일과 링크를 모션 슬롯에 등록할 수 있다.

### 등록 예시

| 슬롯 | 실행 모션 | 자료 |
| --- | --- | --- |
| 자료 A | 왼손 L 모양 | 제품 소개 웹사이트 |
| 자료 B | 오른손 세 손가락 | 가격표 PDF |
| 자료 C | 양손을 바깥으로 벌리기 | 제품 시연 영상 |
| 자료 D | 오른손으로 원 그리기 | 데모 애플리케이션 |
| 발표 복귀 | 손바닥 아래로 이동 | 슬라이드 화면 |

### 안전장치

- 자료 실행 전에 이름을 짧게 표시
- 같은 자료의 연속 실행 방지
- 실행 후 쿨다운 적용
- 발표 프로필에 등록된 자료만 실행
- 외부 링크의 도메인 표시
- 항상 사용할 수 있는 발표 복귀 명령 제공

## 16. 오작동 방지 구조

```
제스처 후보 발견
→ 리허설 동작과 충돌하는지 확인
→ 현재 모드에서 허용된 명령인지 확인
→ 일정 시간 유지했는지 확인
→ 인식 신뢰도 확인
→ 실행 예정 상태 표시
→ 명령 실행
→ 동일 명령 잠금
→ 쿨다운
```

### 명령별 안전 수준

#### 낮은 위험

실수로 실행되어도 쉽게 복구할 수 있는 명령.

- 다음 슬라이드
- 이전 슬라이드
- 레이저 표시

#### 중간 위험

발표 흐름에 영향을 줄 수 있는 명령.

- 커서 모드 전환
- 링크 열기
- 파일 열기
- 앱 실행

#### 높은 위험

발표를 중단할 수 있는 명령.

- 발표 종료
- 화면 공유 종료
- 애플리케이션 종료
- Flickey 종료

높은 위험의 명령은 양손 제스처, 긴 유지시간 또는 2단계 동작을 사용한다.

### 레이저와 화면 공유

사용자가 전체 화면을 공유하면 Flickey 레이저 오버레이가 참석자 화면에도 표시될 수 있다.

그러나 PowerPoint나 브라우저 창 하나만 공유하면 별도 오버레이가 상대방에게 보이지 않을 수 있다.

MVP에서는 다음과 같이 안내한다.

> Flickey 레이저를 참석자에게 보여주려면 전체 화면 공유를 사용하세요.

장기적으로는 발표 프로그램별 연동이나 가상 디스플레이 출력을 검토한다.

### macOS 손쉬운 사용 권한

시스템 커서 이동과 클릭에는 손쉬운 사용 권한이 필요하다.

- 앱의 코드 서명 신원 고정
- 업데이트 후 권한 유지
- 권한 상태 실시간 확인
- 권한이 없을 때 정확한 설정 경로 안내
- 모션 인식과 커서 권한 상태를 분리해 표시

### 발표 프로그램 호환성

초기에는 프로그램별 API보다 키보드 단축키를 전송하는 방식이 현실적이다.

- 다음 슬라이드: 오른쪽 방향키
- 이전 슬라이드: 왼쪽 방향키
- 발표 종료: `Esc`
- 프로그램별 전체화면 단축키
- 프로그램별 화면 가리기 단축키

## 24. 데모 시나리오

### 온라인 제품 발표

1. 발표자가 Flickey에서 발표 프로필을 연다.
2. 리허설 데이터를 기반으로 개인화된 제스처 설정을 불러온다.
3. 오른손을 오른쪽으로 밀어 다음 슬라이드로 이동한다.
4. 양손 검지를 교차한 뒤 오른쪽으로 움직여 레이저 모드에 진입한다.
5. 오른손 검지로 그래프의 특정 수치를 가리킨다.
6. 모드 선택 동작 후 왼쪽으로 움직여 커서 모드에 진입한다.
7. 오른손으로 커서를 이동한다.
8. 왼손을 펼쳤다가 주먹을 쥐어 슬라이드 안의 링크를 클릭한다.
9. 등록된 모션으로 제품 데모 페이지를 연다.
10. 복귀 제스처로 슬라이드 화면으로 돌아온다.
11. 발표가 끝나면 잠금 제스처로 모션 인식을 비활성화한다.

### 데모의 핵심 메시지

> 발표자는 발표 내내 키보드와 마우스를 찾지 않고 청중과 발표에 집중했다.

## 27. 장기 확장 가능성

- `Flickey Present`: 발표 및 온라인 강의
- `Flickey Studio`: 영상·음악·디자인 작업
- `Flickey Stream`: 방송 장면 및 음소거 제어
- `Flickey Access`: 접근성 기반 컴퓨터 제어
- `Flickey Meeting`: 화상회의 반응 및 화면 제어
- `Flickey Demo`: 제품 시연 및 영업 프레젠테이션

확장하더라도 공통된 제품 정체성은 유지한다.

> 사용자의 평소 몸짓을 이해하고, 의도한 움직임만 명령으로 바꾸는 개인용 모션 단축키 레이어.

## 28. 최종 포지셔닝

Flickey를 단순한 웹캠 제스처 앱이나 발표 리모컨으로 소개하지 않는다.

### 최종 정의

> **Flickey는 발표자의 자연스러운 몸짓과 명령 동작을 구분해, 슬라이드부터 커서와 자료까지 제어하는 개인 맞춤형 모션 프레젠테이션 인터페이스다.**

### 가장 먼저 증명해야 할 가치

1. 발표 중 키보드와 마우스를 찾는 횟수가 줄어드는가?
2. 일반 제스처 시스템보다 오작동이 적은가?
3. 사용자가 자신의 제스처를 쉽게 기억할 수 있는가?
4. 커서와 레이저 전환이 발표 흐름을 실제로 개선하는가?
5. 리허설 학습이 개인화 효과를 명확하게 보여주는가?
