# DESIGN-OVERLAY.md — 발표 중 오버레이 디자인 기준

> 적용 범위: **발표 중에 발표 자료 위(또는 카메라 미리보기 위)에 떠 있는 것**만.
> - 손 주변 피드백(테두리·진행 게이지·성공 파동)
> - 모드 전환 시 화면 가장자리 발광과 `SLIDE MODE` / `CURSOR MODE` / `LASER MODE` / `MOTION OFF` 표시
> - 페이지 안 레이저 오버레이와 가상 커서(에이전트 폴백)
> - 에이전트 미니 패널(웹앱은 상태만 보내고, 페이지 안에 같은 모양의 미리보기를 둔다)
>
> 그 밖의 화면(홈, 프로필 설정, 리허설, 제스처 설정, 발표 대기, 로그, 리포트)은 `docs/DESIGN.md`를 따른다.
> 코드 경계: 오버레이 컴포넌트는 `src/ui/overlay/`에만 두고 `src/styles/overlay.css`의 `--ov-*` 토큰만 쓴다. 클래스 접두사 `ov-`.

## 1. 원칙 (기획서 §17)

1. **검정과 건메탈 중심.** 배경은 순수 검정이 아니라 아주 어두운 남회색. 면은 최소 면적.
2. **백청색 발광 하나.** 강조는 색이 아니라 밝기로. 발광은 정보("지금 인식 중", "성공")에만.
3. **어두운 적색 포인트 하나.** 긴급 정지·취소·위험 표시에만. 장식 금지.
4. **작고 정교하게.** 발표 자료를 가리지 않는다. 손 주변 요소는 손 크기의 1.2배를 넘지 않는다.
5. **약 1초 후 소멸.** 모든 피드백은 `--ov-linger`(1000ms) 뒤 사라진다. 남아 있는 것은 미니 패널과 레이저(움직이는 동안)뿐.

## 2. DESIGN.md와의 관계 — 명시적 예외

`docs/DESIGN.md` §1·§6·§8은 그라데이션·글로우·색 그림자를 금지한다. **이 문서의 범위 안에서는 백청색 발광을 허용한다.** 이유:

- 오버레이는 정보 위계를 만드는 UI가 아니라 "지금 인식되고 있다"는 **즉시성 신호**다. 발표 자료 위에 떠 있어 배경을 통제할 수 없고, 어두운 반투명 면 위의 발광이 가장 적은 면적으로 가장 잘 보인다.
- 발표자는 청중을 보면서 주변 시야로 신호를 받는다. 형태·텍스트보다 밝기 변화가 주변 시야에서 먼저 인지된다.
- 예외는 여기까지다. 설정·리허설 화면에 발광을 쓰지 않는다. 오버레이 안에서도 그라데이션 배경·유리 효과·순차 등장은 여전히 금지.

## 3. 토큰 (`src/styles/overlay.css`)

```css
:root {
  --ov-bg:        #0B0D10;   /* 검정 (순수 #000 금지) */
  --ov-gunmetal:  #2A2F36;   /* 건메탈: 패널 면, 테두리 */
  --ov-gunmetal-2:#3A414A;   /* 한 단계 밝은 건메탈: 구분선, 게이지 트랙 */
  --ov-text:      #E6EBF0;   /* 패널 글자 */
  --ov-text-dim:  #9AA4AF;   /* 보조 글자 */
  --ov-glow:      #9FD8FF;   /* 백청색 발광 */
  --ov-glow-weak: rgba(159, 216, 255, 0.35);
  --ov-accent:    #7A1F2B;   /* 어둡고 무게감 있는 적색 */
  --ov-accent-text: #FF8A94; /* 어두운 면 위 적색 글자 (대비 확보용) */

  --ov-shadow-glow:   0 0 12px var(--ov-glow), 0 0 2px var(--ov-glow);   /* 이 문서 범위에서만 허용 */
  --ov-shadow-glow-lg:0 0 24px var(--ov-glow), 0 0 4px var(--ov-glow);

  --ov-radius: 12px;
  --ov-panel-alpha: 0.82;    /* 패널 면 불투명도 */

  --ov-fast:   150ms;        /* 등장 */
  --ov-base:   220ms;        /* 모드 전환 발광 상승 */
  --ov-linger: 1000ms;       /* 소멸까지 */
  --ov-ease-out: cubic-bezier(0.16, 1, 0.3, 1);
  --ov-ease-in:  cubic-bezier(0.4, 0, 1, 1);
}
```

다크·라이트 구분이 없다. 오버레이는 항상 어둡다(발표 자료가 밝든 어둡든 동일).

## 4. 요소별 규격

### 4.1 손 주변 테두리 (인식 중)

- 손 바운딩 원(손목–중지MCP 거리의 1.2배 반지름), 선 두께 1.5px, 색 `--ov-glow`, 불투명도 0.6.
- 발광 없음(상시 표시라 눈부심 방지). 후보가 잡히면(holding) 불투명도 1.0 + `--ov-shadow-glow`.
- 손이 사라지면 `--ov-fast` 안에 사라진다.

### 4.2 진행 게이지 (유지 시간)

- 테두리 원 위에 같은 반지름의 호(arc). 시작 12시, 시계 방향. 두께 3px, `--ov-glow`.
- 상태 표시이므로 애니메이션이 아니다(DESIGN.md 적용 노트와 같은 예외). 60ms 보간만.
- 실행 예정(armed)이면 호가 가득 차고 `--ov-shadow-glow-lg`.

### 4.3 성공 파동

- 실행 순간 손 중심에서 반지름 1.2배 → 2.0배로 퍼지는 원 한 개. 두께 2px → 0, 불투명도 0.8 → 0. `--ov-linger` 동안 `--ov-ease-out`.
- 파동은 한 번. 반복·다중 링 금지.

### 4.4 명령 이름 · 쿨다운

- 손 아래 24px 위치에 `--ov-gunmetal` 면(alpha 0.82) 위 `--ov-text` 13px 굵기 600, `word-break: keep-all`. 예: `다음 슬라이드`.
- 쿨다운은 같은 면 안에서 얇은 하단 바(2px, `--ov-gunmetal-2` 트랙 위 `--ov-glow`)가 줄어든다. 텍스트 "쿨다운"은 쓰지 않는다.
- `--ov-linger` 뒤 소멸. 쿨다운이 더 길면 바가 끝날 때까지 유지.

### 4.5 모드 전환 가장자리 발광 (§12)

- 뷰포트 네 변 안쪽 6px 두께의 `--ov-glow` 선이 `--ov-base` 동안 불투명도 0 → 0.9로 올라왔다가 `--ov-linger` 동안 0으로.
- 중앙 상단에 `SLIDE MODE` / `CURSOR MODE` / `LASER MODE` / `ASSET MODE` / `MOTION OFF` 라벨. 라틴 대문자 고정 폭 느낌을 위해 `letter-spacing: 0.08em`, 13px, `--ov-text`, 면 `--ov-gunmetal`(alpha 0.82). (DESIGN.md §3.3의 대문자 금지는 한글 UI 규칙이며 이 라벨은 영문 고정 표기라 예외.)
- `MOTION OFF`만 라벨 왼쪽에 `--ov-accent-text` 점 하나. 나머지는 `--ov-glow` 점.

### 4.6 레이저 (페이지 안 폴백 · 에이전트 오버레이 공통 규격)

- 점: 지름 `sm 10px / md 14px / lg 20px`, 색 `blue = --ov-glow`, `red = --ov-accent-text`. 점 뒤에 `--ov-shadow-glow`.
- 잔상: 최근 300ms 위치 6개를 지름 60%→10%, 불투명도 0.5→0으로. 선으로 잇지 않는다.
- 정지 강조: 200ms 이상 정지하면 지름 1.6배 링이 `--ov-base` 동안 나타남. 주먹(`emphasis: 1`)이면 2.4배.
- 손이 사라지거나 `hide`면 `--ov-linger` 뒤 소멸.
- **시스템 커서와 무관.** 폴백 오버레이는 `pointer-events: none`.

### 4.7 가상 커서 (페이지 안 폴백)

- 지름 16px 링(1.5px, `--ov-glow`) + 중심점 3px. 발광 없음(정확한 위치 표시가 목적).
- 클릭 순간 링이 0.8배로 줄었다가 복귀(`--ov-fast`).

### 4.8 미니 패널 (에이전트 표시용 규격, 페이지 안 미리보기 동일)

```
┌────────────────────────────┐   면 --ov-gunmetal alpha .82, radius 12, 폭 220px
│ ● SLIDE MODE        ● CAM │   좌: 모드(점 --ov-glow) 우: 카메라 상태
│ ◔ 오른쪽 스와이프          │   인식 중 후보 + 게이지(4.2와 동일 원, 12px)
│ 최근: 다음 슬라이드         │   --ov-text-dim
│            [■ 긴급 정지]    │   --ov-accent 면, --ov-text 글자. 이 패널에서 유일한 적색 면
└────────────────────────────┘
```

- 화면 우하단 기본, 드래그 가능(에이전트 구현). 항상 위, 클릭 통과 아님(버튼이 있으므로).
- `MOTION OFF`일 때 첫 줄 점이 `--ov-accent-text`, 나머지 줄은 `--ov-text-dim`.

## 5. 모션 규칙

- 등장 `--ov-fast`, 모드 발광 상승 `--ov-base`, 소멸 `--ov-linger`(유일하게 320ms를 넘는 값이며 "1초 후 소멸" 요구를 그대로 따른다).
- `transform`과 `opacity`만. 잔상은 위치를 바꾸지 않고 새 점을 그린다(레이아웃 애니메이션 없음).
- `prefers-reduced-motion: reduce`: 파동·잔상·가장자리 발광 상승을 없애고 opacity 전환만 남긴다. 게이지와 레이저 점 자체는 상태 표시라 유지.

## 6. 접근성·안전

- 오버레이는 정보를 색으로만 전달하지 않는다. 모드는 라벨 텍스트, 성공은 파동 + 명령 이름, MOTION OFF는 점 + 텍스트.
- 발광 강도 상한: `--ov-shadow-glow-lg` 이상 만들지 않는다. 깜빡임(3Hz 이상 반복) 금지.
- 카메라가 켜져 있는 동안 미니 패널의 `CAM` 점은 항상 표시된다(§18 카메라 작동 상태 상시 표시).

## 7. 체크리스트 (오버레이 컴포넌트를 만들 때)

```
1. 발표 자료 위에 떠 있는 요소인가? 아니면 DESIGN.md 로 돌아간다.
2. 색이 전부 --ov-* 토큰인가?
3. 발광은 정보(인식 중·성공·모드 전환)에만 있는가? 상시 표시 요소에 발광이 없는가?
4. 1초 뒤 사라지는가? 남아 있어야 하는 것(패널·레이저)만 남는가?
5. 손 주변 요소가 손 크기 1.2배 안에 있는가?
6. 적색은 긴급 정지·MOTION OFF 점·레이저 red 외에 쓰이지 않았는가?
7. prefers-reduced-motion 에서 파동·잔상·발광 상승이 빠지는가?
8. 시스템 커서를 건드리는 코드가 레이저 경로에 없는가?
```
