<h1 align="center">ADAM</h1>

<p align="center">
  <strong>손짓으로 제어하고, 발표에 집중하세요.</strong><br>

ADAM은 웹캠으로 손동작을 인식해 슬라이드와 포인터를 제어하는 발표 보조 도구입니다. 화면에서 떨어져 설명하는 발표자와 강사가 키보드나 마우스를 찾느라 발표의 흐름을 끊지 않도록 돕습니다.

웹에서는 데모 슬라이드와 직접 선택한 PDF로 사용할 수 있습니다.

## 사용하기

> **[ADAM 시작하기 → adamsmith.ai.kr](https://adamsmith.ai.kr)**
>
> 처음이라면 **데모 덱으로 연습**을 선택해 손동작을 익혀보세요.

준비물은 **웹캠이 있는 컴퓨터, 데스크톱 브라우저, 발표할 PDF**입니다. PDF 없이 데모로 먼저 연습할 수도 있습니다. 카메라를 사용하려면 HTTPS 또는 localhost에서 실행해야 합니다.

1. 자료 선택 — 홈의 ‘발표 준비’에서 데모 덱으로 연습 또는 내 PDF 업로드를 선택합니다. 잘못 선택한 PDF는 파일 카드의 ×로 지울 수 있습니다.
2. **발표 시작** — **발표 시작**을 누르면 자료가 별도 팝업에 열립니다. 데모와 PDF 모두 제어센터 카메라가 바로 켜지고, 발표 창에서도 카메라를 연결해 모션을 자동으로 시작합니다. 브라우저가 요청하면 카메라 접근과 팝업을 허용합니다.
3. **모션 켜기** — 데모와 PDF 모두 카메라 권한을 허용하면 모션이 자동으로 시작됩니다. 카메라에 손을 보여주고 데모의 5장 안내를 따라 연습해 보세요.
4. **발표하기** — 손동작으로 페이지를 넘기거나 포인터를 움직입니다. 이전·다음 버튼, 방향키, Home / End와 전체 화면 버튼도 사용할 수 있습니다.
5. **마무리** — 발표 창을 닫습니다. 홈의 제어센터 카메라도 끄려면 **카메라 끄기**를 누릅니다.

### 기본 손동작

| 기능 | 동작 |
| --- | --- |
| 다음 / 이전 슬라이드 | 손바닥을 오른쪽 / 왼쪽으로 스와이프 |
| 화면 가리기 / 다시 표시 | 손바닥을 펼쳐 유지. 다시 실행하려면 손을 내렸다가 다시 보여주기 |
| 포인터 모드 | 엄지와 검지로 L 모양 만들기 |
| 포인터 이동 | 검지를 펴고 손 움직이기 |
| 슬라이드 모드로 복귀 | 검지·중지·약지 펴기 |
| 모션 켜기 / 끄기 | 엄지와 새끼손가락을 편 전화기 모양 유지 |
| 긴급 정지 | 양손 주먹 유지 |
| 발표 종료 | 슬라이드 모드에서 한 손 주먹 유지 |

손 모양은 잠깐 유지해야 인식됩니다. 포인터 모드에서는 슬라이드 이동 명령을 실행하지 않으며, 긴급 정지 후에는 전화기 모양으로 모션을 다시 켤 수 있습니다.

### 나에게 맞게 설정하기

홈의 **설정**에서 입력 방식을 조정합니다.

- **모션 커스텀:** 기능별 손동작을 변경합니다. 사용 중인 모션은 중복 지정할 수 없으며, 다른 기능으로 옮기려면 기존 지정을 ‘지정 안 함’으로 바꿉니다.
- **키보드 커스텀:** 키 버튼을 누르고 원하는 키 또는 Shift 조합을 입력합니다. 모션과 키보드는 각각 전체 초기화할 수 있습니다.
- **포인터 감도 → 감도 설정:** 팝업 안에서 손을 움직이며 감도를 조절합니다. **초기화**를 누르면 1.00×로 돌아갑니다. 팝업은 **×, 바깥 클릭, Esc, Q**로 닫습니다.
- **권한 점검:** 카메라 권한 상태를 확인합니다. 감도 설정에서도 카메라 연결과 권한 오류를 안내합니다.

모션·키 설정과 발표 프로필은 로그인 없이 현재 브라우저의 `localStorage`에 저장됩니다. 같은 브라우저와 주소에서는 새로고침 후에도 유지되며, 사이트 데이터를 삭제하면 초기화됩니다.

## 사용 기술과 동작 원리

| 기술 | 역할 |
| --- | --- |
| **React · TypeScript** | 발표 준비, 설정, 발표 팝업과 상태 관리 |
| **MediaPipe Tasks Vision** | 카메라 프레임에서 손 관절 좌표와 좌우 손 추적 |
| **Canvas · PDF.js** | 손 인식 결과 표시 및 PDF 페이지 렌더링 |
| **브라우저 MediaDevices API** | 카메라 권한 요청과 영상 입력 |
| **Electron · macOS 제어 코드** | 데스크톱 환경의 외부 앱 키 입력·시스템 포인터 제어 기반 |
| **Vite · Vitest · Testing Library** | 개발 서버, 빌드, 동작 테스트 |

### 손동작이 명령이 되는 과정

```text
웹캠 영상 → 손 관절 좌표 추적 → 손 모양·이동 방향 판별
         → 유지 시간·모드·중복 실행 간격 확인
         → 사용자 설정에 맞는 명령 실행
```

MediaPipe가 추적한 손가락과 관절 위치를 바탕으로 손 모양과 이동 방향을 판단합니다. 동작 유지 시간과 실행 간격을 확인해 같은 명령이 연속으로 실행되는 것을 줄이고, 슬라이드·포인터 모드에 따라 실행할 기능을 구분합니다.

포인터 위치에는 사용자가 정한 감도를 적용합니다. 감도 설정 팝업에서는 실제 슬라이드 명령이나 시스템 마우스 클릭 대신 테스트 영역의 포인터만 움직여 변화를 확인할 수 있습니다.

PDF는 브라우저에서 PDF.js로 읽어 Canvas에 표시합니다. 문서의 페이지 수에 맞춰 이동 범위를 정하고, 창 크기에 맞게 페이지를 다시 그립니다.

### 지원 범위와 데이터 처리

- **웹:** 앱 안의 데모·PDF 발표와 포인터 표시를 지원합니다. 외부 PowerPoint·Keynote나 다른 웹사이트를 직접 제어하지는 않습니다. 발표 팝업의 키보드 이동은 방향키와 Home / End를 사용합니다.
- **추가 자료:** 홈에서 이름과 URL을 등록하고 ‘새 탭에서 열기’로 실행합니다. 웹 모션 인식만으로 외부 링크를 자동 실행하지는 않습니다.
- **데스크톱:** Electron과 macOS용 외부 앱 제어 코드가 포함돼 있습니다. 대상 앱과 권한에 따른 동작 확인이 필요합니다.
- **카메라·PDF:** 현재 구현은 카메라 영상을 손 인식에 사용하고 PDF를 로컬에서 읽으며, 이를 서버에 업로드하거나 저장하는 기능은 없습니다.

## 직접 실행하기

Node.js와 npm이 설치된 환경에서 실행합니다. Node.js 버전은 Vite 8의 요구 조건에 맞춰 사용하세요.

```bash
git clone https://github.com/insidesight0921-stack/motion-shortcut.git
cd motion-shortcut/motion-shortcut
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다.

| 명령어 | 용도 |
| --- | --- |
| `npm run dev:electron` | Electron 개발 실행 |
| `npm run build` | 배포용 웹 빌드 생성 (`dist/`) |
| `npm test` | 프런트엔드 테스트 |
| `npm run test:electron` | Electron 관련 테스트 |

## FAQ

| 증상 | 확인 방법 |
| --- | --- |
| 카메라가 켜지지 않음 | HTTPS / localhost 접속 여부와 브라우저·운영체제 카메라 권한 확인 |
| 발표 창이 열리지 않음 | 사이트 팝업 허용 후 ‘발표 시작’ 다시 누르기 |
| PDF가 열리지 않음 | 정상적인 PDF인지 확인. 암호로 보호된 파일은 암호 해제 후 선택 |
| 손동작이 인식되지 않음 | 모션이 켜져 있는지 확인하고, 손 전체가 카메라에 보이도록 위치·조명 조정 |
| 포인터가 너무 빠르거나 느림 | 설정 → 포인터 감도 → 감도 설정에서 조절 |
