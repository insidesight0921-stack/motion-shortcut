# Flickey

> 발표자의 말과 흐름을 끊지 않는 모션 프레젠테이션 컨트롤러

Flickey는 누구나 바로 따라 할 수 있는 고정 손동작으로 슬라이드·커서·레이저·발표 자료를 제어하는 macOS용 모션 프레젠테이션 인터페이스입니다.

별도의 리모컨 없이 웹캠만으로 슬라이드를 넘기고, 하이퍼링크를 클릭하고, 화면에 레이저를 표시하고, 미리 등록한 발표 자료를 열 수 있습니다.

![Flickey 모션 인식 파이프라인](public/assets/motion-shortcut-pipeline.png)

## 핵심 타깃

카메라 앞에서 자료를 공유하며 설명하는 온라인 발표자를 첫 번째 타깃으로 합니다.

- 온라인 강사, 교사 및 교수
- 대학생과 대학원생
- 웨비나 및 화상회의 진행자
- 비대면 영업 및 제품 시연 담당자
- 발표와 화면 공유가 많은 직장인

Zoom, Google Meet, Microsoft Teams, 온라인 강의, 웨비나, 제품 시연 및 오프라인 프로젝터 발표 환경을 우선 지원합니다.

## 핵심 가치

1. **즉시 사용**: 별도의 학습 과정 없이 기본 동작을 바로 사용합니다.
2. **발표 흐름 유지**: 청중을 바라보면서 키보드와 마우스 없이 발표를 제어합니다.
3. **통합 제어**: 슬라이드, 커서, 레이저, 링크 및 파일을 하나의 인터페이스에서 다룹니다.
4. **명확한 모드 분리**: 슬라이드·커서·레이저 모드를 구분해 의도하지 않은 입력을 줄입니다.
5. **로컬 처리**: 웹캠 영상과 손 관절 정보는 기기 안에서 처리합니다.

## 사용 흐름

```text
발표 프로필 생성
→ 발표 프로그램 선택
→ 웹 슬라이드라면 발표 링크 지정
→ 발표 자료 등록
→ 카메라 및 고정 동작 테스트
→ 모션 ON
→ 실시간 발표 제어
→ 모션 OFF
```

## 발표 제어 모드

### 슬라이드 모드

- 다음·이전 슬라이드
- 발표 화면 가리기
- 발표 종료
- 등록한 웹 링크 및 로컬 파일 실행

### 커서 모드

- 오른손으로 시스템 커서 이동
- 왼손을 펼쳤다가 주먹 쥐어 클릭
- 슬라이드 안의 하이퍼링크 진입
- 웹페이지, 버튼 및 영상 조작

커서 모드에서는 슬라이드 명령을 비활성화해 포인터 조작 중 슬라이드가 넘어가는 것을 방지합니다.

### 레이저 모드

- 오른손 검지를 따라 백청색 레이저 이동
- 실제 시스템 커서와 분리된 강조 포인터
- 클릭 없이 안전하게 발표 화면 강조
- 전체 화면과 모든 작업 공간 위에 표시

레이저 모드에서는 실제 시스템 커서를 움직이지 않으므로 링크나 버튼이 실수로 클릭되지 않습니다.

## 고정 모션

현재 버전에서는 모든 사용자에게 같은 기본 동작을 제공합니다.

| 기능           | 고정 손동작                       |
| -------------- | --------------------------------- |
| 다음 슬라이드  | 손바닥을 펴고 오른쪽으로 스와이프 |
| 이전 슬라이드  | 손바닥을 펴고 왼쪽으로 스와이프   |
| 화면 가리기    | 손바닥 펼치기 약 0.8초            |
| 발표 종료      | 주먹 쥐기 약 1초                  |
| 다음 자료 선택 | V 사인 약 0.7초                   |
| 선택 자료 실행 | 검지 하나 약 0.7초                |
| SLIDE 모드     | 양손 펼치기 1.6초                 |
| CURSOR 모드    | 양손 검지 X 1.6초                 |
| LASER 모드     | 양손 V 사인 1.6초                 |
| 커서 이동      | 오른손 검지 또는 붙인 검지·중지   |
| 클릭           | 왼손 펼치기 후 주먹 쥐기          |
| 모션 ON/OFF    | 전화 모양 약 1.2초                |
| 긴급 정지      | 양손 주먹 1.2초                   |

모드 모션을 인식하는 동안에는 슬라이드 명령이나 클릭이 함께 실행되지 않습니다.

## 발표 자료 슬롯

발표 전에 원하는 수만큼 자료를 등록하고 고정 모션으로 열 수 있습니다.

- V 사인으로 등록된 자료를 순서대로 선택
- 검지 하나로 현재 선택된 자료 실행
- 슬롯 이름 변경
- 등록한 자료 직접 테스트
- 설정은 현재 Mac에 저장

## 웹 슬라이드 링크

프로필에서 Google Slides, Canva, Pitch, Gamma 등의 발표 링크를 직접 입력하고 **링크 열기·제어 대상으로 지정**을 누를 수 있습니다. Flickey가 서비스 종류를 판별하고 Chrome으로 링크를 연 뒤, 해당 브라우저를 슬라이드 명령 대상으로 사용합니다. 링크는 발표 프로필에 저장됩니다.

## 인식 파이프라인

```text
웹캠 입력
→ 손 랜드마크 추적
→ 좌표 정규화
→ 정적 포즈 또는 이동 궤적 판정
→ 현재 발표 모드 확인
→ 유지시간과 신뢰도 확인
→ 동일 명령 중복 확인
→ 명령 실행
→ 쿨다운 및 실행 로그 저장
```

## 오작동 방지

- 앱을 실행할 때 모션은 항상 OFF입니다.
- 고정 포즈는 종류에 따라 약 0.6~1.2초 유지하면 실행됩니다.
- 모드 전환은 지정된 양손 모션을 1.6초 유지해야 합니다.
- 양손 주먹을 1.2초 유지하면 어느 모드에서든 즉시 정지합니다.
- 동일한 명령의 연속 실행을 제한합니다.
- 현재 모드에서 허용된 명령만 실행합니다.
- 커서와 레이저는 모션이 ON일 때만 움직입니다.
- 실행 결과와 실패 원인을 앱 화면에 표시합니다.

## 개인정보 보호

- 카메라 영상과 관절 데이터는 기기 내부에서 처리합니다.
- 카메라 원본 영상을 저장하거나 외부 서버로 전송하지 않습니다.
- 카메라와 모션 인식 상태를 화면에 표시합니다.
- 모션 OFF 상태에서는 발표 명령을 실행하지 않습니다.
- 카메라를 끄면 비디오 트랙을 해제하고 모션·커서·레이저도 함께 정지합니다.

## 기술적 고려사항

### 레이저와 화면 공유

전체 화면을 공유할 때는 Flickey 레이저 오버레이가 참석자 화면에도 표시될 수 있습니다. PowerPoint나 브라우저 창 하나만 공유하면 별도 오버레이가 보이지 않을 수 있으므로 현재 버전에서는 레이저 사용 시 전체 화면 공유를 권장합니다.

창 하나만 공유해야 할 때는 레이저 설정의 **창 공유 호환**을 켭니다. 이 모드에서는 레이저와 시스템 커서를 함께 움직여, 공유 서비스가 마우스 포인터를 전송하는 경우 참석자도 강조 위치를 볼 수 있습니다. 서비스에서 포인터 공유를 끈 경우에는 전체 화면 공유가 필요합니다.

### macOS 권한

시스템 커서 이동, 클릭 및 슬라이드 키 입력에는 손쉬운 사용 권한이 필요합니다.

1. 시스템 설정을 엽니다.
2. 개인정보 보호 및 보안 → 손쉬운 사용으로 이동합니다.
3. Flickey를 허용합니다.
4. Flickey를 완전히 종료한 뒤 다시 실행합니다.

## 설치 파일로 실행

`release` 폴더에서 아래 파일을 사용할 수 있습니다.

- `Flickey-1.0.0-arm64.dmg`: Apple Silicon Mac 설치용
- `Flickey-1.0.0-arm64.zip`: 압축 배포용

처음 실행할 때 개발자 공증 경고가 표시되면 Finder에서 앱을 우클릭하고 **열기 → 열기**를 선택합니다. 이후 카메라 및 손쉬운 사용 권한을 허용합니다.

현재 배포본은 Apple Silicon(M1 이상) Mac용이며 Apple 개발자 공증은 포함되지 않습니다.

## 개발

필요 환경:

- Node.js 20 이상
- macOS
- Xcode Command Line Tools

```bash
npm install
npm run dev:electron
```

검증:

```bash
npm run lint
npm test
npm run build
```

Apple Silicon 배포본 생성:

```bash
sh scripts/build-icon.sh
npm run dist:mac
```

배포 결과는 `release` 폴더에 생성됩니다.

## 확장 방향

고정 모션 기반 발표 제어를 먼저 안정화한 뒤 개인화 학습과 다른 작업 환경으로 확장합니다.

- **Flickey Present**: 발표 및 온라인 강의
- **Flickey Meeting**: 화상회의 제어
- **Flickey Demo**: 제품 시연 및 영업 프레젠테이션
- **Flickey Studio**: 영상·음악·디자인 작업
- **Flickey Stream**: 방송 장면과 음소거 제어
- **Flickey Access**: 접근성 기반 컴퓨터 제어
