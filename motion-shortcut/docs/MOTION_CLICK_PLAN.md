# 모션 클릭 효과 계획

현재는 구현하지 않습니다. 손 추적과 제스처 인식이 안정된 뒤 모션 클릭 피드백에 적용합니다.

원본 참고 코드는 `click-effects-originkit-reference.txt`에 보존했습니다.

## 적용 방식

1. MediaPipe 검지 끝 랜드마크 `8`을 화면 좌표로 변환합니다.
2. 엄지와 검지의 거리 또는 검지 유지시간으로 클릭 후보를 만듭니다.
3. 클릭 후보가 유지시간과 쿨다운 검사를 통과했을 때만 클릭을 확정합니다.
4. 확정 좌표에 Originkit 효과 중 하나를 생성합니다.
5. 효과 애니메이션이 끝나면 해당 객체를 제거합니다.

## 효과 사용 기준

- `rings`: 일반 클릭의 기본 피드백
- `sniper`: 작은 버튼을 정확히 선택했을 때
- `particles`: 앱 실행처럼 강한 성공 피드백
- `burst`: 짧고 빠른 명령 완료 피드백
- `crosshair`: 클릭 후보를 유지하는 동안의 조준 표시
- `wavy`: 오류나 취소가 아닌 부드러운 보조 피드백

## 구현 시 주의점

- 원본의 전역 `document` 클릭 리스너를 그대로 사용하지 않습니다.
- 마우스 좌표가 아니라 손끝 랜드마크 좌표를 입력받는 `triggerEffect(x, y, mode)` 형태로 분리합니다.
- 후보 단계에서는 crosshair만 표시하고 확정 전에는 실제 앱 명령을 실행하지 않습니다.
- 효과 DOM은 `pointer-events: none`으로 유지합니다.
- GSAP는 실제 적용 시점에만 의존성으로 추가합니다.
- `prefers-reduced-motion` 사용자는 축소된 링 효과만 사용합니다.
- 카메라 좌우 반전과 앱 화면 좌표 변환을 한곳에서 처리합니다.
